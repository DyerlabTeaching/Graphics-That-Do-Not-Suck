# Graphics that Don't Suck

![](https://raw.githubusercontent.com/DyerlabTeaching/Graphics-That-Do-Not-Suck/main/media/graphics.png)

## Impetus

This is a slightly larger topic because it encompasses both classic graphics in `R` as well as graphics via `ggplot2`.

## Module Learning Objectives

### Construct Univariate and Bivariate Visualizations

> Learners will create plots of both continuous and categorical data, using both base R graphics and `ggplot2`, appropriate to whether one or two variables are being displayed.

- **Bloom's Levels:** Apply
- **Reinforces:** Applies the data types (Basic Data Types) and factors (Factors) covered earlier as the raw material being visualized.
- **Notes:** Covers both classic R plotting and `ggplot2` side by side rather than treating them as separate topics.

### Customize Visual Encodings for Clarity

> Learners will customize symbology and color choices based on properties intrinsic to the data, to make visualizations more interpretable and less misleading.

- **Bloom's Levels:** Apply, Evaluate (judging what representation communicates the data well)
- **Reinforces:** Sets the visualization standard used for presenting results in every later module's narrative and homework.
- **Notes:** The title's implicit standard — a "graphic that doesn't suck" — is operationalized here as thoughtful symbology and color use, not decoration.
